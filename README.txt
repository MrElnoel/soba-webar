MEET SOBA — WEBAR

This folder contains the original Soba image, the animation, and a ready-to-host WebAR page.

IMAGE TARGET READY
The supplied targets.mind has been included. No compiling needed.

PUBLISH ON GITHUB PAGES
1. Create a new public GitHub repository (e.g. soba-webar).
2. Upload index.html, soba.png, soba.mp4, and targets.mind into the repository root.
3. Go to Settings > Pages > Build and deployment > Deploy from a branch; select main and /(root), then Save.
4. Open the HTTPS GitHub Pages URL on your phone and allow camera access.
5. Point the phone at the original Soba image on a separate screen or print.

NOTES
- HTTPS and camera permission are required.
- On iPhone, use Safari for initial testing.
- The video is muted to improve mobile autoplay compatibility.
- If tracking is unreliable, try a printed image with good lighting and avoid glare.
- The provided video is landscape (3362x2176), while the target PNG is portrait (1325x2048). The webpage preserves the video's aspect ratio; alignment may need adjustment after your first camera test.
